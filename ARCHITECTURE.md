# Architecture

> **For AI agents:** This document describes the system structure so you can
> navigate, modify, and extend the codebase confidently. Read this first.

## What This Is

A minimal static site generator that compiles Markdown insight papers into a
styled HTML publication. No framework, no database, no client-side JavaScript.
The entire rendering pipeline is one TypeScript file.

## System Map

```
content/*.md  ──▶  scripts/build.tsx  ──▶  dist/*.html  ──▶  server.ts  ──▶  HTTP :PORT
  (input)           (transformer)          (output)          (static server)   (consumer)
```

| Component | File | Role |
|---|---|---|
| Content | `content/*.md` | Markdown files with YAML frontmatter. **Git-ignored** — produced by external synthesis pipeline. |
| Build | `scripts/build.tsx` | The entire build system. Reads content, generates HTML. |
| Server | `server.ts` | Static file server with security headers. Serves `dist/`. |
| Output | `dist/*.html` | Compiled HTML pages. **Git-ignored** — generated by build. |
| Dependencies | `package.json` | React/remark are listed but the build uses a hand-rolled markdown parser. tsx is the runtime. |

## Build Pipeline (`scripts/build.tsx`)

### Functions (in execution order)

1. **`page(opts: PageOptions): string`** — HTML page template. Takes title,
   body content, active nav state, and renders the full `<html>` document with
   inline `<style>`. All CSS lives here. This is the single source of truth
   for visual design.

2. **`mdToHtml(md: string): { html, frontmatter }`** — Minimal Markdown → HTML
   converter. Handles: frontmatter parsing, code blocks, inline code, headers
   (h1-h3), bold/italic, links, blockquotes, horizontal rules, tables, lists,
   and paragraphs. Returns both HTML and parsed frontmatter.

3. **`stripLeadingH1(html: string): string`** — Removes the first `<h1>` tag
   (the title is rendered separately in the paper template).

4. **`excerptFrom(md: string): string`** — Extracts a ~220 char plain-text
   excerpt for archive listings.

5. **`build()`** — Main entry point. Cleans `dist/`, collects all `.md` files
   from `content/` (sorted newest-first), and generates four page types:
   - **Paper pages** (`{slug}.html`) — individual insight articles
   - **Index** (`index.html`) — homepage with status panel + featured paper
   - **Archive** (`archive.html`) — chronological list of all papers
   - **About** (`about.html`) — system description

### Key constants

- `SYNTHESIS_CADENCE` — String displayed in status bar (e.g. `"EVERY 4H"`).
  Change this to match your pipeline's actual cadence.

## Server (`server.ts`)

Minimal `http.createServer` with:
- Configurable `HOST` (default `127.0.0.1`) and `PORT` (default `18805`)
  via environment variables
- Security headers: CSP, X-Frame-Options, X-Content-Type-Options,
  Referrer-Policy, Permissions-Policy
- `/health` endpoint returning `{ "status": "ok" }`
- Static file serving with automatic `.html` extension fallback
- Path traversal protection (`filePath.startsWith(ROOT)` check)
- GET/HEAD only; all other methods return 405

## Content Format

```markdown
---
title: "Your Insight Title"
date: YYYY-MM-DD
tags: tag1, tag2
---

# Your Insight Title

Your markdown content here...
```

- Files are named `YYYY-MM-DD-slug.md`
- Sorted by filename descending (newest first)
- The leading `# H1` is stripped from output (title comes from frontmatter)

## Extending

### Add a new page type

1. Build the body HTML string inside `build()`
2. Call `page({ title, body, active, wide })` to wrap it
3. Write to `dist/yourpage.html`

### Modify the design

All CSS is in the `page()` function's inline `<style>` block. Change a CSS
custom property in `:root` to re-theme globally.

### Connect an external synthesis pipeline

1. Write `.md` files into `content/` following the format above
2. Run `npx tsx scripts/build.tsx` to regenerate `dist/`
3. Restart or hot-reload the server (no watch mode built in)

## What's NOT in This Repo

- **Content** — `content/` and `dist/` are git-ignored. They are generated at
  runtime by an external synthesis pipeline and may contain private data.
- **Database** — None. Pure filesystem.
- **Client JS** — None by design (CSP: `script-src 'none'`).
- **Build framework** — None. Just `tsx` executing TypeScript directly.
- **External fonts/images** — None by design (CSP: `font-src 'self'`, `img-src 'self' data:`).
